# Contributing

Thanks for helping! Contributions of all sizes are welcome.

## Good first contributions
- **Add or correct a material** (density, print temperatures) with a source (manufacturer datasheet).
- **Translate** the UI or README (we support English, Português and Español; more languages welcome).
- **Report a wrong result**: open an issue with your inputs, the result you got and the result you expected.

## How to contribute
1. Fork the repo and create a branch: `git checkout -b my-change`
2. Make your change and run the tests (see README).
3. Open a pull request describing **what** changed and **why** (link a source for any data change).

## Ground rules
- Keep it dependency-free and simple.
- Formulas must match the documented ones in the README; if you change a formula, update the README and tests.
- Be kind. See the Code of Conduct.

The full set of calculators lives at [SizeBench](https://sizebench.com/3d-printing).
